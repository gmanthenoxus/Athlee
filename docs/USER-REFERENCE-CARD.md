## 💡 Quick Tips

### Login
1. Go to `/login`
2. Enter any username from this list
3. Click "Login" (no password needed)
4. Profile auto-generates
5. View profile at `/profile`

### Clear Cache & Start Fresh
```javascript
// Browser console:
await import('@athlehub/shared').then(m => m.clearAllCaches());
// Then refresh page or login with different user
```

### Switch Users
1. Click "Logout" in navigation
2. Login with different username
3. New profile loads (or generates if first time)
